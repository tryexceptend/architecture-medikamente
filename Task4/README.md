# Рекомендации

| №     | Рекомендации                                                                                                                                                                                                                                                                                  | Приоритет |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| **1** | **Персонал**                                                                                                                                                                                                                                                                                  |           |
| 1.1   | Обучение персонала новому функционалу. Для ускорения обучения необходимо создать базу знаний, в которой будут описаны процессы и методы работы. Там нужны обучающие видео, алгоритмы работы, ссылки на ресурсы. Данный ресурс надо начать создавать на этапе разработки.                      | Средний   |
| 1.2   | Ужесточение норм безопасности. Необходимо проводить обучение по правилам безопасности. Нужно объяснять причины ужесточения прав и правил работы. В случаях выявления незначительных нарушений не наказывать, а проводить разъяснительную работу.                                              | Высокий   |
| 1.3   | Найм квалифицированных разработчиков. Найм разработчиков, девопсов и прочего лучше отдать на аутсорс квалифицированной компании.                                                                                                                                                              | Высокий   |
| **2** | **Тенологии**                                                                                                                                                                                                                                                                                 |           |
| 2.1   | Нет архивирования данных. Необходимо разработать инструкцию по созданию архивов данных. С указанием отвественных, алгоритмом действий. Так же нужно надежное хранилище, для хранения архивных данных.                                                                                         | Высокий   |
| 2.2   | Необ                                                                                                                                                                                                                                                                                          |           |
| **3** | **Оборудование**                                                                                                                                                                                                                                                                              |           |
| 3.1   | Отсутствует резервирование данных. Файлы хранятся на общем диске, что черевато их потерей, в случае выхода из строя оборудования. Необходимо настроить резервное копирование всех данных. Или RAID массив дисков                                                                              | Высокий   |
| 3.2   | Данные хранятся на незашифрованных носителях. Необходимо реализовать шифрование пользовательских директорий и общих дисков                                                                                                                                                                    | Высокий   |
| 3.3   | Для миграции необходима закупка дорогостоящего ПО. Предлагается перенести часть данных и сервисов в облачне хранилища, для экономии                                                                                                                                                           | Низкий    |
| 3.4   | Нет резервирования систем. Необходимо ввести дублирование для всего оборудования, что бы сократить риск потери данных. Это дублирование дисков, внедрение ИБП, резервные каналы связи.                                                                                                        | Высокий   |
| **4** | **Разработка**                                                                                                                                                                                                                                                                                |           |
| 4.1   | Нет тестовых данных для интеграционных тестов и разработки. Предлагается начать с создания тестовой базы, с помощью PHP скриптов. Необходимо скремблирование символов всей конфендициальной информации. На этих данных будет вестись разработка и тестирование                                | Средний   |
| 4.2   | Нет опыта разработки. Необходимо нанять опытного руководителя разработки. Найм лучше предоставить сторонней проверенной организации.                                                                                                                                                          | Высокий   |
| 4.3   | Разработка затронет все элементы системы, что потребует большого времени. Предлагается вести разработку в парадигме микросервисной архитектуры. Можно внедрять новые элементы постепенно, заменяя некоторые элементы системы. Применяется паттерн Strangler Fig.                              | Высокий   |
| **5** | **Интеграция**                                                                                                                                                                                                                                                                                |           |
| 5.1   | Файлы пациентов не структурированы. Предлагается перенести все файлы в S3 хранилище. Необходимо присвоить теги всем файлам, для их структуризации и упорядочивания. Для этого можно воспользоваться системой DataGrail                                                                        | Высокий   |
| **6** | **Процессы**                                                                                                                                                                                                                                                                                  |           |
| 6.1   | Персонал имеет доступ к данным, которые им не нужны. Пока нет разработанных порталов для персонала, необходимо доступ к данным сделать через систему DataGrail. Это позволит настроить авторизированный доступ к данным и убрать лишние права                                                 | Высокий   |
| 6.2   | Есть альтернативные потоки передачи данных: элемтронная почта, файловые обменники, меседжеры. Необходимо провести обучение персонала в части информационной безопасности. Так же надо настроить алертинг, при обнаружении фактой передачи конфидециальной информации через сторонное резурсы. | Средний   |
| 6.3   | Персонал привык работать с файлами. Переход на новые системы может быть труден для персонала. Надо уделить внимание обучению работе в новых системах, поощрять активную работу и внедрение.                                                                                                   | Средний   |
