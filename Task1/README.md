# Анализ системы медицинского центра "Медикаменте"

## Текущее состояние (As-Is)

### Проблемые зоны

1. Хранение персональных данных клиентов:
   
   1. Данные клиентов хранятся в незашифрованном хранилище;
   
   2. Нет контроля целосности данных клиентов;
   
   3. Отсутствуют решения для предотвращения утечки данных (DLP);
   
   4. Отсутствует тегирование данных;
   
   5. Отсутствует резервирование данных;

2. Доступ к персональным данным клиентов:
   
   1. Доступ к данным клиентов не ограничен только доменной политикой безопасности;
   
   2. Пользователь, которому нужен доступ к данным одного клиента, получает доступ к данным всех клиентов;
   
   3. Пользователь, которому нужен доступ на редактирование данных одного клиента, получает доступ на редактирование данных всех клиентов;
   
   4. Нет ролевой модели доступа к данным (RBAC);
   
   5. Нет обезличивания данных для обработки в целях бизнеса; 

3. Хранение финансовых данных фирмы
   
   1. Финансовые данные хранятся на незашифрованном носителе;
   2. Отсутствует резервирование данных;

4. Аудит действий и доступа к данным
   
   1. Отсутствует аудит доступа к данным;
   
   2. Отсутствует мониторинг действий пользователей;
   
   3. Отсутствует отслеживать нетипичные действия пользователей и оповещения о них;

5. Масштабируемость
   
   1. Данные хранятся в неудобном для интерации формате (Excel файлы);
   
   2. Нет удобных форматов для интеграции с API других систем;  

6. Классификация данных
   
   1. Нет классификации данных;
   
   2. Данные разной значимости хранятся вместе.

### Меры защиты

#### Защита данных

Для защиты данных в разных система предлагается следующая схема:

| Данные                               | Способы защиты                                  |
| ------------------------------------ | ----------------------------------------------- |
| Персональные данные клиентов         | Шифрование                                      |
| Медицинские данные клиентов          | Шифрование                                      |
| Финансовые данные                    | Шифрование                                      |
| Данные по платежам                   | Обфускация или токенизация                      |
| Данные клиентов для сторонних систем | Токенизация                                     |
| Данные клиентов в отчетности         | Обфускация                                      |
| Данные для тестирования              | Скремблирование символов, зануление или подмена |

#### Тегирование данных

Для реализации механизма тегирования данных и контроля потоков данных предлагается использовать **DataGrail**.

- подходят компаниям с ограниченным бюджетом;

- подходит для несложных сред;

- быстро настраиваются и легко интегрируются.

Предлагается выделить следующие категории данных

| Данные                                                                     | Тэг                                 | Расшифровка                                   |
| -------------------------------------------------------------------------- | ----------------------------------- | --------------------------------------------- |
| Данные клиента: Ф.И.О, телефон, электронная почта, адрес                   | private_client_data [PCD]           | Персональные данные клиентов                  |
| Платежные данные клиента: платежные реквизиты, счета, данные карт, платежи | finance_client_data [FCD]           | Платежная информация клиентов                 |
| Медицинские данные клиента                                                 | medical_client_data [MCD]           | Медицинские данные клиентов                   |
| Медицинские анализы клиента от сторонних систем                            | raw_medical_laboratory_data [RMLCD] | Необработанные  лабораторные анализы клиентов |
| Финансовые данные компании: платежные реквизиты, счета, отчетность         | finance_data [FD]                   | Платежная информация клиентов                 |
| Данные клиентов переданные в аналитику                                     | analitic_client_data [ACD]          | Обфусцированные данные клиентов для аналитики |
| Данные складского учета                                                    | warehouse_data [WD]                 | Данные складского учета                       |
| Внутренние данные компании                                                 | private_data [PD]                   | Приватные данные                              |
