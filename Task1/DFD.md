# Данные для DFD

- **Источники данных.** 
  - Пациенты;
  - Администраторы на ресепшене;
  - Доктора;
  - Кассиры;
  - Бухгалтера;
  - Сотрудники склада.
  
  
- **Процессы.** 
  - Получение данных от пациента администратором на ресепшене;
  - Получение 
  - Это действия, которые выполняют с данными. Например, хранение, преобразование, анализ. Процессы изображают в виде узлов или блоков обработки.
  
  
- **Хранилища данных.** 
  - Journals - директория с Excel файлами журналов записи пациентов по докторам;
  - Pacients - директория с файлами пациентов, распределенные по отдельным директориям;
  - Laboratory Registry - директория с реестром анализов;
  - 1C Бухгалтерия предприятия - файловое хранилище "1C Бухгалтерии предприятия";
  - 1C Торговля и склад - файловое хранилище "1C Торговля и склад";
  - Exchange Mail Server - почтовый сервис внутренней почты.
  
  
- **Потоки данных.** 
  - Регистрация пациента;
  - Запись пациента на прием;
  - Регистрация файлов с данными пациента;
  - Оплата услуг пациентом;
  - Товарный учет на складе.
  
  
- **Внешние субъекты.** 
  - Налоговый департамент
