# Стратегия защиты данных

1. **Определить, какие данные нужно защитить**.
   
   Необходимо классифицировать информацию по состоянию, чувствительности, профилю риска и другим параметрам. Это поможет выбрать наиболее эффективные методы защиты.

2. **Реализовать базовые инструменты защиты**.
   
   Предложить инструменты защиты, которые нужно добавить в систему, чтобы обеспечить защиту данных.

3. **Использовать автоматизированный контроль**.
   
   Предложить средства для контроля за данными

4. **Подготовить реестр программных и аппаратных средств для защиты данных**.

## 2. Средства контроля за данными

Для контроля за данными предлагается внедрить **DataGrail**. Эта система может:

- определять потоки данных;

- присваивать теги данным;

- удалять данные по запросу;

- предоставлять систему получения согласия от пользователей на обработку персональных данных;

- контролировать доступ к данным.

Использование Elasticsearch позволяет использовать плагины для поиска персональных данных в логах, паролей и т.д.

## Программные и аппаратные средства для защиты данных.

1. Использование шифрования директорий пользователей и носителей.

2. Протоколы передачи данных HTTPS с шифрованием не ниже TLS 1.3;

3. Использование серевых экранов с защитой от атак;

4. Применение политики контроля доступа по атрибутам доступа - Keycloack, Active Directory, DataGrail.

5. Необходимо внедрять обфускацию данных на уровне микросервисов, при отправке в "озеро данных".

6. Все системы должны отслеживать события, связанные с безопасностью, и записывать, кто выполнил действие, какое действие было выполнено и когда оно произошло. Это сохраняется в отдельный лог системы безопасности DataGrail.

7. Использование защищенного S3 хранилища позволит реализовать контроль за доступом в фалам пациентов. Можно использовать облачные решения от **Yandex Object Storage** или **TimeWeb**. При использовании свои ресурсво можно использовать **MinIO** или **SeaweedFS**.

8. В качестве "озера данных" предлагается использовать структурированные логи в Elasticsearch. Это бесплатное решение, которое позволяет хранить большой объем информации. Предоставляет удобные механизмы поиска и фильтрации данных. Так же есть контроль доступа к данным, возможность сокрытию полей, контроль данных, которые попадают в хранилище (поиск паролей, конфиденциальной информации).
